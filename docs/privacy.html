Privacy policy

Effective November 27, 2026

ek-gelir-yt is a personal publishing tool operated by its owner in the Netherlands. It uses YouTube API Services and is intended for use solely by the owner of the authorized YouTube channel.

Information accessed and purpose

The application requests Google OAuth permissions youtube.upload and youtube.force-ssl to upload the owner's videos, thumbnails and captions. The application receives OAuth access and refresh tokens and upload responses, including the uploaded video identifier. It is not designed to retrieve viewer profiles, comments or other channels' private information. It does not use Google user data to train AI models, for advertising or for sale.

Storage and disclosure

Credentials must be kept in protected server configuration or GitHub Actions secrets, not in public source code. Uploaded video identifiers, URLs and upload status may be retained in project records; operational logs may also contain upload status and errors. The project is hosted on GitHub and may run on GitHub Actions or the owner's server. Data is sent to Google/YouTube for the authorized publishing operations. No Google user data is sold or used for unrelated purposes.

Retention, revocation and deletion

OAuth credentials are retained while authorization is needed. The owner can revoke access at any time using Google account permissions and remove stored credentials and project records. For questions or requests concerning deletion of retained API data or credentials, contact ondermuratt73@gmail.com. Revoking application access does not automatically delete videos already uploaded to YouTube; these can be managed through YouTube Studio.

Google and YouTube policies

Use of the application is subject to the YouTube Terms of Service. Google's handling of personal data is described in the Google Privacy Policy. The application is intended to use Google user data only for its disclosed publishing functionality, in accordance with the Google API Services User Data Policy.
