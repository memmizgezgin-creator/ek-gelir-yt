ek-gelir-yt

A personal publishing tool for the owner's YouTube channel, producing English-language documentaries about industrial engineering, machine tools and cutting-tool history.

How it works

The tool prepares original scripts, licensed illustrations, narration and captions, then uses YouTube Data API v3 to upload finished videos, thumbnails and captions to the channel authorized by the owner. It does not offer a public sign-in or publishing service to third parties.
